# PSOC&trade; Control C3M/P8: ADC-CPU-HW3P3Z-CPU-TCPWM data flow

This code example applies for PSOC&trade; Control C3M/P8 MCUs. It demonstrates the data flow between ADC, Hardware 3P3Z filter and TCPWM handled by the CPU. 

A TCPWM channel configured as PWM is used for triggering the conversion of the ADC channel on its terminal count. The End of Conversion signal from ADC triggers an interrupt to the PPCA CPU 0, then the output of the ADC is copied to the HW 3P3Z filter by the CPU inside the ISR. Writing of data to the HW Filter triggers the HW filter processing. The End of Processing signal of the filter causes an interrupt to the PPCA CPU 0, then the output of the 3P3Z filter will be copied to the compare 0 register of the TCPWM inside the ISR. 

The PPCA CPU 0 sends ADC output and HW filter output to the main CPU. The main CPU prints it on the UART console. 

The 3P3Z filter is configured in such a way that the duty cycle of the PWM output will be varied along with the ADC input voltage. The ADC input is from a potentiometer on the EVK. So that the user can see that the PWM pulse width is getting modulated when the potentiometer is rotated. 

The PWM output is connected to an LED(D13) and pin P6.0 on the EVK. It helps the user to monitor the PWM modulation on the LED, also on an oscilloscope.

## Design and implementation

This code example showcases the capability of the PSOC&trade; Control C3M/P8 MCU to transfer data between ADC, HW3P3Z filter and TCPWM by the CPU by generating interrupts after the completion of the processing in each stage. This MCU has 4 different ADC Groups. In this code example the first channel from the first ADC group, the first channel from the 2nd HW filter and the first channel from the TCPWM 1 group 0 are used.  

**Figure 2. Peripheral configuration**

![](images/peripheral-configuration.png)

The figure 2 shows the peripheral configuration of the code example, first channel from the ADC Groups 0 is triggered through the EPU by the TCPWM[1].Group[0].Channel[0] which is configured in PWM mode. EPU Combiner 60 and EPU processing unit T1 0 are used for that. 

On completion of the conversion of the ADC, an interrupt is triggered. Inside the ISR the converted data will be fed to the HW 3P3Z filter 0 in Hardware Filter 3P3Z Group 1. Writing of the data to the HW filter triggers the filter processing.

The HW3P3Z filter is configured just to provide the required gain to the input to make it in the range of the TCPWM duty cycle. It will process the input data and generate an ISR. Inside the ISR the data will be moved to the TCPWM Compare 0 register. TCPWM[1] Group [0] Counter[0] is used here.

Along with these, the PPCA CPU 0 will share the data with the main CPU. The main CPU will send this data to the PC through the debug UART. Figure 1 shows the debug UART capture.

Figure 3 shows the timing of the peripheral activities in the code example. 

**Figure 3. Timing diagram**

![](images/timing-diagram.png)

Figure 4 shows the relation between the ADC input from the potentiometer and the width of the PWM. When the potentiometer output goes up, the width of the pulse comes down and vice versa. The same signal is connected to LED D13 on the EVK. You can see the LED brightness increasing when the potentiometer is rotated in the clockwise direction, i.e. when the width of the PWM decreases.
